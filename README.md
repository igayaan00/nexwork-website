# NEXWORK Website v2 (Next.js)

## Run in VS Code
1. Extract `nexwork-website-v2.zip` (Extract All).
2. Open the extracted folder directly in VS Code.
3. Open Terminal (`Ctrl + ~`) and run:
   npm install
   npm run dev
4. Open http://localhost:3000 in your browser.

## Admin Panel
- Click "Admin Login" in the Footer (or go to http://localhost:3000/admin)
- Default Username: admin
- Default Password: nexwork@123
- You can change the password anytime inside the Security tab.
